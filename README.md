# Cascaded Stealth-Aware ATT&CK Path Prediction

This repository contains the source code, trained model weights, and evaluation data for a cascaded prediction framework that forecasts the next technique an adversary is likely to employ in a MITRE ATT&CK sequence. The framework fuses an LSTM sequence model with a tactic-admissibility gate and a Sigma-derived stealth re-ranker, producing ranked attack paths that are both tactically coherent and evasion-aware. Evaluation follows a prefix-disjoint protocol on the MITRE ATT&CK Sightings v2 corpus, ensuring that no evaluated context appears in training.
